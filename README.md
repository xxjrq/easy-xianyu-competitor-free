# 免费闲鱼竞品分析

在已登录的闲鱼浏览器里搜索同类商品，整理公开可见的价格、成色、规格、卖点和交易方式，输出可核对的对比表。免费使用，不需要第三方 API Key。

## 使用前先准备

安装并启动 [Easy WebBridge](https://github.com/xxjrq/easy-webbridge)，备用地址是 [Gitee](https://gitee.com/xxjrq/easy-webbridge)。在 EasyBR 中登录闲鱼，告诉智能体要使用的 `browserId` 和账号别名。没有 EasyBR 时，只能分析你手动提供的页面或文本。

## 示例

“使用 `$easy-xianyu-competitor-free`，在 `easybr-xianyu-a` 搜索机械键盘，整理 20 条公开结果，给出价格带和常见卖点，不要收藏或联系卖家。”

报告只反映当时页面看见的样本，不代表全站行情，也不保证成交。
